# knowledge-map

一个给 Claude Code 和 Codex 用的 skill：把课件、讲义、录播字幕或论文画成能点着看的知识关系图。

成品是一个不联网也能打开的 HTML。知识点是节点，点开有不看原文也能读懂的详细解释；连线写明知识点之间的关系，可以跨章节；还可以按“关系链”一步一步看。

## 获取

两种方式任选一种：

- 下载 [Releases](../../releases) 里的 `knowledge-map.zip`，解开是一个 `knowledge-map` 文件夹。
- 或者克隆这个仓库，用里面的 `knowledge-map` 文件夹。
