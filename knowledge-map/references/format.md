# 数据文件怎么写

一张图对应一个数据文件 `<名字>.kmap.toml`，`build.py` 把它生成同名的 `<名字>.html`。数据文件和 HTML 放在一起，以后要改，只改数据文件再生成。

## 先记住三条

1. **用编辑文件的工具写（Claude Code 用 Write，Codex 用 apply_patch），不要用 echo、printf 这类 shell 命令写。** 通过 shell 写文件时，`\\` 会被吃掉一个反斜杠，公式就坏了。
2. **带反斜杠或要换行的文字，一律用三个单引号 `'''…'''` 包起来。** TOML 的双引号字符串会把 `\f`、`\t` 当转义，公式会出错或报格式错误。
3. **字面上的美元符号写成 `\$`。** 单个 `$` 是公式的开头，例如价格 `\$0.6`。

## 顶层

```toml
title = "Week 10 · RAG 知识关系图"     # 页面标题
intro = "一句话说明这张图讲什么。"      # 可选，显示在标题下面
mode = "paper"                         # 可选，course 或 paper；paper 会多查论文主线和 evidence
notes = '''
可选。全图通用的说明，例如页码按 PDF 算、哪些数字没有核实、完整的引用格式。
页头会多一个“说明”链接，点开在面板里看；文字版开头也会显示。
'''

[[sources]]                            # 至少一个；节点和关系的 src 引用这里的 id
id = "S1"
name = "Lewis2020_RAG.pdf"             # 短名，例如“作者 年份，期刊”；它会出现在页头和每条出处里
kind = "论文"                          # 课件、论文、字幕、讲义、笔记……显示在出处前面
```

说明性的话不要塞进 `name`：超过 80 个字 `build.py` 会警告。

## 分区 `[[zones]]`

```toml
[[zones]]
id = "method"
title = "③ 本文方法"
sub = "§3"                  # 可选，小字跟在标题后面
grid = [1, 0]               # 第几列、第几行（分区之间的网格，从 0 数）
size = [3, 4]               # 区内有几列、几行（节点的网格）
color = 3                   # 可选，1 到 8；不写按顺序轮换
title_align = "end"         # 可选，标题放右上角；有连线穿过左上角标题时用
```

同一网格列的分区一样宽，同一网格行的分区一样高，按最大的那个算。

## 节点 `[[nodes]]`

```toml
[[nodes]]
id = "rrf"                  # 英文短 id，关系和关系链用它
zone = "method"
pos = [1, 2]                # 区内第几列、第几行；可以写 0.5 这样的半格
title = "RRF"               # 框里的大字：原文的术语，越短越好
sub = "只看名次 · k = 60"    # 框里的小字：不超过 14 个汉字
one = "把几份排名合成一份，只看名次不看分数。"        # 一句话定义
detail = '''
**是什么：** ……

**怎么做：** ……
'''
more = '''
算例、推导、代码、长公式放这里，默认收起。
'''
src = [
  { s = "S1", loc = "p34–35", quote = "ignores scores and uses positions" },   # quote 照抄原文，不改写、不翻译
]
sup = '''
原文没有、为了讲懂补充的内容放这里。
'''
# background = true         # 整个节点是原文默认读者已会的背景知识；这时 src 可以不写
# evidence = "实测"          # 证据等级：实测、模拟、设想，见 writing.md 第 5 节；概念、方法这类节点不写
```

## 关系 `[[edges]]`

```toml
[[edges]]
id = 15
from = "hybrid"
to = "rrf"
label = "分数不可比 → 用"    # 线上的字，尽量不超过 8 个汉字
kind = "good"               # good、bad、part、link、evid，含义见 writing.md
text = "BM25 分数和 cosine 分数没法比，所以用 RRF 只按名次合并（p34）。"
src = [{ s = "S1", loc = "p34" }]
# inferred = true           # 原文没有直接说、是推断出来的关系；这时 src 可以不写
# evidence = "模拟"          # 证据等级，和节点的写法一样；常用在“证明”“显示”这类 evid 关系上
# bend = 40                 # 线往旁边弯，用来绕开别的节点；正数往行进方向的右手边弯
# lp = 0.3                  # 线上文字的位置，0.1 到 0.9，默认 0.5（中点）
```

## 关系链 `[[chains]]`

```toml
[[chains]]
title = "为什么要两种检索器"
intro = "可选，第一步之前先说一句背景。"
edges = [7, 9, 8, 10, 13, 14, 15]
```

## 文字里能用的写法

`one`、`text`、`intro` 只写一句话；`detail`、`more`、`sup`、`notes` 可以写多段。

| 写法 | 效果 |
|---|---|
| 空一行 | 分段 |
| 行首 `- ` | 圆点列表；下一行缩进就接在这一项后面 |
| 行首 `1. ` | 数字列表 |
| `**粗体**` | 粗体，用来做段首的小标题，例如 `**是什么：**` |
| `` `code` `` | 代码字体 |
| `$x^2$` | 行内公式 |
| `$$ … $$` | 独立成块的公式，太宽时可以左右滑动 |
| `\$` | 字面上的美元符号 |

公式用 LaTeX 写，生成时由 latex2mathml 转成浏览器自带的 MathML，不联网也能显示。

- 多行公式用 `\begin{align*}` 或 `\begin{split}`；`aligned` 和 `gathered` 会被转坏，`build.py` 会报错。
- 矩阵用 `bmatrix` 或 `pmatrix`，分段函数用 `cases`。
- 公式里的中文放进 `\text{…}`。
- 范数用 `\|x\|`。
